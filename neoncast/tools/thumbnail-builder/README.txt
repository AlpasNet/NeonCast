NeonCast Thumbnail Builder — PHP

Open index.php through a PHP-enabled web server.

Features:
- 1280 x 720 live thumbnail preview and PNG export
- NeonCast retro 80s color themes
- Custom background, circular portrait and thumbnail logo
- Persistent configuration saved in data/thumbnail-config.json
- Saved configuration loads automatically the next time the page is opened
- New image uploads replace the previously saved background, portrait or logo file
- Header uses assets/config-logo.png

Writable paths required by PHP:
- assets/
- data/

Supported uploaded image formats: JPG, PNG and WEBP.

Radio Stars font:
Place Radio Stars.otf in the fonts/ directory.
